# Offline Algorithm for ADS
## Introduction
This algorithm is part of a group project in the course Algorithms for Decision Support (INFOMADS) at the Utrecht University. This project is a research project about the single machine scheduling problem with multiplicative interruption penalties. Our goal of the project was to find an algorithm in the online context and conduct some proofs with it. 
A major part of project as well, was to write a algorithm for the offline context. That algorithm is provided in this repository.
